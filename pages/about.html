About This Project

This server was built for Assignment 6 to demonstrate routing with Node's core http module, asynchronous file reading with fs.readFile, and modular code organization (routing logic lives in routes.js, separate from server.js).

It responds with correct HTTP status codes: 200 for valid pages, 404 for unknown routes, and 500 if a page file can't be read.
